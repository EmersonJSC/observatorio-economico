# Fontes de dados

Cada integração deve registrar aqui a fonte oficial, dados obtidos,
periodicidade, licença/atribuição, chave de junção territorial e limitações.

## Fontes planejadas

| Domínio | Fonte | Uso inicial |
| --- | --- | --- |
| Território e indicadores | IBGE | malhas, localidades, população e indicadores sociais |
| Economia | IBGE / Banco Central | PIB territorial e contexto macroeconômico |
| Gestão pública | Siconfi / Tesouro Nacional | receitas, despesas e execução fiscal |
| Eleições | TSE | candidaturas, votos e resultados eleitorais |

O arquivo de cada fonte deve conter a data da última sincronização e o período
de referência apresentado ao usuário.
